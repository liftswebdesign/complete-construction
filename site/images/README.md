# Image provenance

The current hero, about section, and project gallery use 25 unique project JPEGs supplied in Wintersville Construction.zip. See projects/README.md and ../../docs/project-image-provenance.json for their source mapping and hashes. The JPEG files are byte-identical copies of the supplied originals; only CSS crops gallery covers. Project dialogs preserve full image proportions. The six source Facebook-post screenshots are kept under docs/project-post-screenshots. Garage images are still screenshots, not videos.

home-concept.png is the original AI-generated architectural illustration created during the initial demonstration on November 5, 2026. It remains retained as an unused historical asset and is not displayed as company work.

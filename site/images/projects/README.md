# User-supplied project photos

25 unique JPEG images imported unchanged from Wintersville Construction.zip, supplied by the requester for use in this website. One byte-identical duplicate was omitted. Six company Facebook-post screenshots are retained under docs/project-post-screenshots as caption evidence, not rendered as gallery photos.

src/project-images.json maps each original image to its project, alt text, and caption. docs/project-image-provenance.json records original filenames, destination names and SHA-256 hashes. All JPEG bytes are unchanged; image cropping in gallery cards is CSS presentation only. The modal displays each full image with its aspect ratio preserved.

Garage images are phone screenshots with black borders, retained as supplied and labeled stills. The ZIP contains no video files or Google review screenshots. Do not present these stills as playable videos or add testimonial quotes without source evidence. No AI imagery is used in the current visible hero, about, or project gallery.
